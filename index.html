discrete‑lic

Every pixel of the starting noise is exactly one pure colour — red, green or blue. The noise is smeared along the streamlines of a vector field, and afterwards every pixel is still exactly one of the three. Which one depends on the colour that won along its streamline.

Notes

Ordinary line integral convolution takes a field of white noise and averages it along the streamlines of a vector field. The result is a smooth, combed texture that shows the shape of the flow.

Here the noise is replaced by a texture of pure primaries: (255, 0, 0), (0, 255, 0) and (0, 0, 255). After convolution each pixel holds a proportion of red, green and blue. The proportions are sharpened by an exponent and one primary is drawn at random. Up close it is coloured noise; from further away the flow appears as a mosaic, like-coloured cells gathering along the same lines.

The pure_rgb mode has no practical signal-processing use. It exists because it looks interesting.

To run it locally

git clone https://github.com/simonpelz/discrete-lic
cd discrete-lic
pip install -r requirements.txt

# Voronoi cells, about one second
python src/lic_main.py \
  --field perlin_curl \
  --color pure_rgb \
  --pixel-mode voronoi

# local preview at http://localhost:8000
uvicorn web.server:app --reload
