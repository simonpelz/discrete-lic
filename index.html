discrete-lic

Line Integral Convolution over discrete RGB primaries. Each noise pixel is exactly one pure color — red, green, or blue. LIC convolution smears these primaries along streamlines of a vector field. Every output pixel is still one primary; which one depends on which color dominated its streamline.

What is discrete-primary LIC?

Standard LIC convolves a white-noise texture along streamlines of a vector field, producing a smooth, oriented texture. Discrete LIC replaces white noise with a texture where every pixel is exactly one of three pure primaries — (255,0,0), (0,255,0), or (0,0,255).

After convolution, each output pixel holds a probability distribution over the three primaries. A sharpness exponent is applied, then one primary is sampled. The result reveals flow topology as a mosaic: every pixel is still one pure color, but like-colored pixels cluster along streamlines.

This mode (--color pure_rgb) has no practical signal-processing use. It exists because it looks interesting.

Quick start

Clone and run — no build step.

git clone https://github.com/YOURNAME/discrete-lic
cd discrete-lic
pip install -r requirements.txt

# Voronoi-pixel mode (~1 s)
python src/lic_main.py \
  --field perlin_curl \
  --color pure_rgb \
  --pixel-mode voronoi

# Interactive web preview
uvicorn web.server:app --reload
# → http://localhost:8000
